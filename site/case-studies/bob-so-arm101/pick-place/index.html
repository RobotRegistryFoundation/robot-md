Status: page minted with placeholders ahead of the trial. The cert id, log index, and elapsed-seconds figures are filled in by a follow-up commit immediately after the cert lands on the RRF transparency log.

What you need

  • Raspberry Pi 5 (8 GB) or similar Linux SBC
  • SO-ARM101 arm (USB-serial)
  • Luxonis OAK-D depth camera (Lite, Pro, or S2 — any OAK-D variant works)
  • Standard red Lego 2×4 brick
  • Matte ceramic bowl, roughly 10 cm inner diameter, contrasting color (cream works)
  • Camera mount: bird's-eye, ~30 cm above the table, pointing straight down

The mount geometry

The find_bowl_top heuristic searches a depth band of 200–350 mm. Set your mount height so the bowl rim falls inside that window — at ~30 cm with a 3 cm rim that comes out to roughly 270 mm, well centered.

The find_red_blob heuristic uses fixed HSV thresholds for a standard red Lego brick. Off-spec lighting or non-red bricks will need a re-tune; that's intentional. The verification is meant to be cheap and inspectable, not robust.

Run it yourself

  1. Run the Spec A cold install — see the cookbook.
  2. Install the gateway: robot-md install-gateway.
  3. Set the cold-install wall-clock anchor before any further install: 
    date -u +%FT%TZ > ~/.robot-md-cold-install-start.txt
  4. Export the gateway envelope env vars (used by every trial iteration call): 
    export ROBOT_MD_RURI=rcan://RRN-000000000002/skill
export ROBOT_MD_MANIFEST_PATH=$HOME/.robot-md/ROBOT.md
export ROBOT_MD_GATEWAY_BEARER=$(cat ~/.robot-md/gateway-bearers/actuate)
  5. robot-md trial start --property bob.local/PICK-PLACE-10
  6. Open Claude Code. The using-robot-md skill auto-loads with the pick-place protocol. Let Claude run.
  7. Repeat 10× per iteration:
    • robot-md trial iteration --trial <id> --capture-pre
    • Claude composes the pick → place sequence and dispatches moves via the gateway.
    • robot-md trial iteration --trial <id> --capture-post-and-verdict
    • Reset the brick → robot-md trial iteration --trial <id> --reset-confirmed
  8. robot-md trial finalize --trial <id>
  9. On the controller machine: opencastor-ops/scripts/hil/orchestrate.py --property PICK-PLACE-10 --trial <id>

What's in the cert

Each iteration captures pre/post depth + RGB frames, the verdict (red brick centroid inside bowl footprint AND depth delta ≤ 80 mm), Claude's dispatched envelopes (audited by the gateway), and the wall-clock from cold-install to first pass.

What this proves and what it doesn't

Proves: on this specific rig with these props, Claude-driven pick-place can happen 10 times in a row with the measured wall-clock.

Does NOT prove: any rig with any brick will hit the same numbers. Verification is HSV + depth, so lighting matters. The arm has no per-motion HiTL claim — envelopes are batch-signed by bob-operator-2026. This case study doesn't carry safety claims for the arm.

Reproduce on your rig

Substitute <your-rig>.local/PICK-PLACE-10 for the property name. The cert namespace stays rig-local until a canonical promotion (deferred until a second rig registers).
