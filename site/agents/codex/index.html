§ 01 — Install

Add robot-md to Codex CLI.

Sandbox note: The Codex CLI sandbox blocks MCP tool calls by default. Pass --dangerously-bypass to enable MCP tool execution. Only use this in trusted environments.

Step 1 — Install the CLI

$ pip install robot-md

Step 2 — Launch Codex with the MCP server

$ codex --mcp-server "npx --yes robot-md-mcp ./ROBOT.md" \
  --dangerously-bypass
§ 02 — Example

Using ROBOT.md from a Codex prompt.

# From your robot project directory:
$ codex --mcp-server "npx --yes robot-md-mcp ./ROBOT.md" \
