# robot-md v0.9.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the `rcan-py` SDK dependency and scaffold §22-§26 RCAN 3.0 schema slots, all additive. After this release, ROBOT.md manifests can declare EU AI Act compliance fields, but no field is required yet and no signing is performed.

**Architecture:** A dependency bump (`rcan>=3.0,<4.0`) unlocks SDK primitives for later releases. Five new optional objects join `schema/v1/robot.schema.json` (one enum on `metadata`, four objects under `compliance`). `robot-md validate` grows a second-pass hook that calls `rcan.validate` in non-strict mode and logs warnings. No enforcement, no signing, no tightening of existing fields — those are v0.9.1-v0.9.4.

**Tech Stack:** Python 3.10-3.13, jsonschema (existing), pyyaml (existing), rcan (new dep), ruff, pytest.

**Spec:** `docs/superpowers/specs/2026-04-21-v0.9-rcan-3-compliance-design.md` sections "v0.9.0 — detailed scope" and "Risks / unknowns (v0.9.0)" are the authoritative scope. Do not widen.

**Budget:** One focused session (~60-90 minutes).

**Out of scope (punt to later sub-releases — do NOT leak in):**
- Signing / ML-DSA / Ed25519 hybrid (v0.9.1)
- FRIA enforcement / Annex-III gating logic (v0.9.2)
- §23/§24/§25/§26 internal sub-schema depth (v0.9.3 — v0.9.0 only adds permissive `"type": "object"` shells)
- RURI construction (v0.9.1)
- RCN/RMN/RHN registry IDs (v0.9.4)

```python
def validate_manifest_dict(manifest: dict) -> tuple[list[str], list[str]]:
    """Validate a manifest dict. Returns (errors, warnings)."""
    errors: list[str] = []
    warnings: list[str] = []

    # Primary: jsonschema
    errors.extend(_jsonschema_errors(manifest))  # existing code; rename if needed
    if errors:
        return errors, warnings  # short-circuit — SDK adds no signal to a broken manifest

    # Secondary: rcan-py SDK pass (non-strict in v0.9.0).
    try:
        import rcan  # noqa: PLC0415 — lazy import; SDK is a runtime dep but we
                    # want validate() to work even if the SDK is temporarily broken.
        sdk_result = rcan.validate(manifest)  # API name — adjust if Task 1 Step 3
                                              # found a different entry point.
        for w in getattr(sdk_result, "warnings", []) or []:
            warnings.append(f"rcan-sdk: {w}")
        for e in getattr(sdk_result, "errors", []) or []:
            # v0.9.0: SDK errors are WARNINGS (non-strict). Strict mode in v0.9.2.
            warnings.append(f"rcan-sdk: {e}")
    except Exception as exc:  # noqa: BLE001 — SDK must never break validate
        warnings.append(f"rcan-sdk: second-pass skipped ({exc})")

    return errors, warnings
```
