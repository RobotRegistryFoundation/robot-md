# robot-md-mcp (npm, v0.2.0)

> This package is a migration stub. The MCP server now ships as part of
> the Python `robot-md` package. Install with pipx/uv, and update your
> `claude mcp add` registration.
>
> Full guide: https://robotmd.dev/docs/migrate-to-python

## tl;dr

```
pipx install robot-md
claude mcp remove robot-md
claude mcp add robot-md -- robot-md-mcp /path/to/ROBOT.md
```

The old v0.1.3 npm package remains installable from npm for anyone
pinning it — it's frozen, no new features.
